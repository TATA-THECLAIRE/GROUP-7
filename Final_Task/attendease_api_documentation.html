🤖Face Recognition AI System
Register Face Profile POST
/api/face-recognition/register
Register user's face profile for attendance verification using AI face recognition technology
Authentication: Bearer token required
Security: Face data is encrypted and stored securely. Multiple face angles required for accuracy.

Request Body (multipart/form-data):

face_images (array of files, required)
3-5 face images from different angles (JPG/PNG, max 5MB each, min 400x400px)
user_id (integer, required)
User ID for face profile registration
quality_threshold (float, optional)
Minimum face quality score (0.0-1.0, default: 0.7)
Success Response:
{
  "success": true,
  "message": "Face profile registered successfully",
  "face_profile_id": "fp_123456789",
  "quality_scores": [0.92, 0.88, 0.91, 0.89],
  "encoding_status": "completed",
  "verification_ready": true
}
Verify Face for Attendance POST
/api/face-recognition/verify
Verify user identity using face recognition during attendance check-in process
Authentication: Bearer token required
Security: Real-time liveness detection prevents spoofing attacks. Confidence threshold: 85%

Request Body (multipart/form-data):

face_image (file, required)
Live face image for verification (JPG/PNG, max 5MB)
session_id (integer, required)
Active attendance session ID
liveness_check (boolean, optional)
Enable liveness detection (default: true)
confidence_threshold (float, optional)
Minimum confidence score (0.0-1.0, default: 0.85)
Success Response:
{
  "success": true,
  "verified": true,
  "confidence_score": 0.94,
  "user_id": 123,
  "verification_id": "ver_987654321",
  "liveness_passed": true,
  "processing_time_ms": 1250,
  "message": "Face verification successful"
}
